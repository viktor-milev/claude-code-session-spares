# Start-spares prompt

The user types this into the sitting session, at the desktop app itself. It must be typed at the desktop: the app starts sessions only on the user's own typed words there. A phone message, a scheduled task or another session cannot start one.

Replace `<N>`, `<Role>`, `<Project>` and the paths before giving it to the user.

---

Start <N> spares for the <Role> seat.

- Start <N> new sessions with your own model, effort and permission mode.
- Title them "Spare 1 - <Role>" to "Spare <N> - <Role>".
- Give each the waiting brief at `<path to spare brief>`, with its number filled in.
- Detach each one to top level.
- File them in the sidebar group "Spares" (create it if it does not exist).
- Record their session ids, in order, in `<path to spares list>`, each with state "waiting".

Then report the list back to me, and any session that did not start.
